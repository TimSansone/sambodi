CLEARCUT BACKGROUND REMOVER

Double-click "Open Clearcut.cmd".
Do not open an HTML file directly.

It will:
1. Start a private web server on your computer.
2. Open Clearcut in your default browser.

Keep the minimized "Clearcut Local Server" window running while using the app.
Your images are processed in the browser and are not uploaded.

The first background removal downloads the AI model and can take a minute.
