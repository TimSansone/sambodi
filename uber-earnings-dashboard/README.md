# Uber Earnings Dashboard

A mobile-friendly, single-page earnings tracker configured for a 2025 Toyota Camry Hybrid.

## Run it

Open `index.html` in Chrome, Edge, Safari, or Firefox.

## Included

- Manual driving-session entry
- Fares, tips, promotions, trips, hours, and mileage
- Fuel-cost estimation
- Maintenance and depreciation allowances
- Estimated tax reserve
- Net hourly and per-mile earnings
- Daily chart, insights, history, browser storage, and CSV export
- Editable Camry Hybrid vehicle assumptions

## Data storage

All data stays in the browser through `localStorage`. Clearing browser site data will remove saved sessions, so use CSV export for backups.
